# PDF Escolar

Aplicación de escritorio local para seleccionar páginas de uno o varios PDF y unirlas en un único documento.

El proyecto utiliza Python, PySide6 y pikepdf. El objetivo es ofrecer una interfaz clara en español para Windows y macOS, sin subir documentos a Internet.

## Estado

Prototipo inicial en desarrollo. La selección por rangos y la exportación se están implementando primero; la selección visual por miniaturas, el reordenamiento y los instaladores firmados quedan para siguientes etapas.
