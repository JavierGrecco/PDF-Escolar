# Avisos de terceros de PDF Escolar

PDF Escolar incorpora bibliotecas creadas por otros desarrolladores. Cada componente conserva su propia licencia y sus avisos de copyright.

**El inventario completo se genera durante la compilación de cada versión.** Incluye las versiones instaladas en ese paquete y los textos de licencia que se encuentran en las distribuciones de sus dependencias. El contenido puede variar entre Windows, macOS Intel y macOS Apple Silicon.

Esta plantilla acompaña al código fuente. Si la ves dentro de una ejecución desde el repositorio, no es el inventario de un instalador concreto. En la aplicación descargada, el menú **Ayuda → Licencias y componentes** muestra el manifiesto generado para ese paquete.

La licencia MIT de PDF Escolar se mantiene separada de las licencias de terceros. El código de PDF Escolar no cambia ni reemplaza las condiciones de las bibliotecas incluidas.

La lista se genera automáticamente como ayuda de transparencia y mantenimiento. No es una certificación legal ni sustituye la revisión manual de licencias, avisos de copyright y componentes nativos que pueda incorporar cada herramienta de empaquetado.
